# Decision Template

**Status:** v1.1 | **Date:** 2026-11-18 | **Owner:** Founder | **Review:** As needed

## Template structure

```
Decision: [title]
Date: [YYYY-MM-DD]
Status: [proposed | approved | rejected]
Decision-maker: [founder]
Context: [why the decision is needed]
Options: [A, B, C ...]
Chosen: [option]
Rationale: [why chosen]
Outcome: [result]
Security impact: [low | medium | high]
Budget impact: [USD amount or n/a]
```

## Sections

1. Context
2. Options
3. Chosen option
4. Rationale
5. Outcome
6. Security impact
7. Budget impact
8. Related decisions (supersedes / superseded-by)

## Notes

- One decision per register entry.
- All decisions recorded in `02_GOVERNANCE/Decision_Register.md`.
- Security and budget impacts are mandatory fields.
