# Hermes Engine — Project Context

**Status:** Assessment | **Version:** 1.0 | **Date:** 2026-11-18 | **Owner:** Founder | **Review:** As needed

## Overview

Hermes Engine is the proposed managed execution engine for the enterprise. It is the most mature project context and sets the pattern for the others.

## Purpose

A managed execution engine that runs bounded tasks under delegated authority, applying the Agent Constitution, Zero Trust Doctrine, and Security Constitution.

## Measurable outcome

A production-ready execution engine capable of running delegate tasks securely, with logging, audit, and human-approval gates.
