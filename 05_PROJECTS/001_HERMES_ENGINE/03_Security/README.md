# Hermes Engine — Security

**Status:** Assessment | **Date:** 2026-11-18 | **Owner:** Founder

## Purpose

Security requirements for the Hermes Engine project, derived from the Security Constitution and Zero Trust Doctrine.

## Controls

- Least-privilege access.
- Encrypted data at rest and in transit.
- Network segmentation; production isolated.
- Audit logging for privileged actions.

## Review

Security review at each milestone; full review quarterly.
