# Source of Truth

**Status:** v1.1 | **Date:** 2026-11-18 | **Owner:** Founder | **Review:** Annual

## Purpose

Defines the authoritative source for each domain of knowledge, and how drafts, approvals, deletions, and archival are handled.

## Authoritative sources by domain

| Domain | Source |
|--------|--------|
| Strategy | Master Constitution + Vision/Mission/Ambition |
| Finance | Financial Doctrine + Decision Register |
| Security | Security Constitution + Zero Trust Doctrine |
| Governance | Human Approval Policy + Model Consultation Protocol + Decision Register |
| AI | Agent Constitution + AI Onboarding Context |
| Projects | per-project `00_Project_Context.md` |

## Draft vs approved

- Draft: marked `version: draft`
- Approved: marked `version: ratified` (or a version number)
- A document is authoritative only when ratified or approved.

## Deletion

- Do not delete authoritative documents; move to the archive folder and note the removal.
- Deletions are proposed in the Decision Register and approved by the founder.

## Archival

Archived documents are moved to `04_KNOWLEDGE_MANAGEMENT/Archive/` with a pointer in the parent document.
